## 系統概述

海洋設備 QR Code 管理系統是一個內部設備資產管理平台，專為海洋調查設備部門設計。

### 主要功能
- ✅ 設備資產管理（CRUD + 檔案上傳）
- ✅ QR Code 標籤管理
- ✅ 校正管理與提醒
- ✅ 維護記錄追蹤
- ✅ 活動日誌（含附件）
- ✅ 帳號與權限管理
- ✅ 響應式設計（Desktop/Tablet/Mobile）

### 系統特色
- 🔐 雙因素認證（2FA）
- 📱 手機友善介面
- 🌐 同網域訪問（WiFi/VPN）
- 📎 完整附件管理
- 🔍 時效性提醒（Dashboard）

## 核心功能

### 1. Dashboard（儀表板）

**用途**: 快速掌握需要注意的事項

**顯示內容**:
- 🔧 **Maintenance Due**: 需要維護的設備數量
- 📊 **Calibration Due**: 需要校正的設備數量
- ⏰ **Overdue Rentals**: 逾期租賃數量
- **Recent Activities**: 最近 10 筆設備異動

**操作**:
- 點擊警報卡片 → 跳轉到相關頁面
- 點擊設備代碼 → 查看設備詳情

### 2. Equipment（設備管理）

#### 2.1 設備列表
**路徑**: Equipment

**功能**:
- 查看所有設備
- 搜尋設備（資產編號、廠商、型號）
- 篩選（類別、狀態）
- 點擊卡片查看詳情

#### 2.2 新增設備
**權限**: Manager, Admin

**步驟**:
1. 點擊 "+ Add Equipment"
2. 填寫表單：
   - **Category**: 設備類型（MBES, GNSS, SVP 等）
   - **Manufacturer**: 廠商
   - **Model**: 型號
   - **Serial Number**: 序號（選填）
   - **Purchase Date**: 購買日期（選填）
3. 點擊 "Create Equipment"
4. **資產編號自動生成**（例如：MBES-2025-001）

#### 2.3 編輯設備
**步驟**:
1. 進入設備詳情頁
2. 點擊 "Edit"
3. 可編輯：
   - **Equipment Status**: 設備狀態（8 種）
   - **基本資訊**
   - **檔案附件**: 照片、手冊、校正報告
   - **Maintenance Records**: 維護記錄
   - **Specifications**: 規格說明

#### 2.4 設備狀態操作
**權限**: Operator, Manager, Admin

**可用操作**（依當前狀態）:
- **Deploy Equipment**: 部署設備
- **Return Equipment**: 回收設備
- **Send to Repair**: 送修
- **Send to Calibration**: 送校正

#### 2.5 設備狀態說明

| 狀態 | 說明 | 顏色 |
|------|------|------|
| Ordering | 採購中 | 黃色 |
| In Stock | 庫存中 | 綠色 |
| Deployed | 部署中 | 藍色 |
| Rented | 租賃中 | 紫色 |
| Repair | 維修中 | 橙色 |
| **Calibrating** | **校正中** | **青色** |
| Disposed | 已報廢 | 灰色 |
| Lost | 遺失 | 紅色 |

### 3. Calibrations（校正管理）

#### 3.1 校正工作流程

**完整流程**:

**步驟 1: 送出校正**
1. Equipment 詳情頁
2. Status Actions → **"Send to Calibration"**
3. 輸入備註（選填）
4. 設備狀態 → CALIBRATING

**步驟 2: 建立校正記錄**
1. Calibrations 頁面 → **"+ Add Calibration"**
2. 搜尋並選擇設備
3. 填寫：
   - Calibration Date（校正日期）
   - Next Due Date（下次到期日期）
   - Provider（校正供應商）
   - Certificate Number（證書號碼）
   - Cost（費用，選填）
   - Notes（備註）
4. 點擊 "Create Calibration"

**步驟 3: 上傳校正報告**
1. Calibrations 表格 → 點擊 **"Edit"**
2. 在 "Calibration Report" 區塊
3. 選擇 PDF 檔案 → **"Upload"**
4. 檔案自動關聯到校正記錄

**步驟 4: 設備歸還**
1. Equipment 詳情頁 → "Edit"
2. 修改 Status → "In Stock"
3. 完成校正流程

#### 3.2 查看校正報告

**方式 1**: 直接在列表查看
- Calibrations 表格
- **Report** 欄位
- 點擊 **📄 View** → 開啟 PDF

**方式 2**: 編輯模式查看
- 點擊 "Edit"
- 查看 "Calibration Report" 區塊
- 點擊檔案連結

#### 3.3 篩選功能

**篩選選項**:
- **All Calibrations**: 所有校正記錄
- **Overdue**: 已逾期
- **Due in 7 Days**: 7 天內到期
- **Due in 30 Days**: 30 天內到期

**狀態標籤**:
- 🔴 **Overdue**: 已過期
- 🟠 **Urgent**: 7 天內到期
- 🟡 **Due Soon**: 30 天內到期
- 🟢 **Normal**: 正常

**步驟 2: 上傳附件**

**步驟 3: 下載/刪除附件**

### 5. QR Code 管理

#### 5.1 QR Code 設定

**一次性設定** (`.env` 檔案):
```env
QR_CODE_DOMAIN=192.168.1.100:5173
QR_CODE_PROTOCOL=http
```

**更新現有 QR code**:
```cmd
cd backend
venv\Scripts\activate
python update_qr_codes.py
```

#### 5.2 使用 QR Code

**列印標籤**:
1. Equipment 詳情頁
2. 點擊 "Download QR"
3. 列印 PNG 圖片
4. 貼在設備上

**手機掃描**:
1. 手機相機對準 QR code
2. 點擊跳出的連結通知
3. 自動開啟設備資訊頁面
4. 已登入 → 顯示完整資訊 + 記錄掃描位置
5. 未登入 → 顯示基本資訊 + 提示登入

## 詳細操作指南

### 登入與安全

#### 首次登入
1. 訪問系統
2. 輸入帳號密碼
3. **設定 2FA**:
   - 使用 Google Authenticator 或 Microsoft Authenticator
   - 掃描 QR Code
   - **記錄備用碼**（重要！）
   - 輸入 6 位數碼驗證
4. 完成設定

#### 日常登入
1. 輸入帳號密碼
2. 輸入 TOTP 6 位數碼
3. 勾選 **"Remember this device for 7 days"**（選填）
4. 登入成功

**記住裝置功能**: 勾選後 7 天內同一裝置登入無需 2FA

---

### 設備管理詳細操作

#### 檔案上傳
**位置**: Equipment 編輯頁面 → File Attachments 區塊

**支援檔案**:
- **Equipment Photo**: JPG, PNG, GIF, WebP（圖片）
- **Equipment Manual**: PDF, DOC, DOCX（手冊）

**步驟**:
1. 點擊 "Choose File"
2. 選擇檔案（最大 10MB）
3. 點擊 "Upload"
4. 上傳成功 → 顯示下載連結

**刪除檔案**:
- 點擊現有檔案旁的 "Delete" 按鈕

#### 維護記錄
**位置**: Equipment 編輯頁面 → Maintenance Records 區塊

**欄位**:
- **Last Maintenance Date**: 最後維護日期
- **Next Maintenance Due**: 下次維護到期
- **Maintenance Notes**: 維護歷史筆記

**用途**: 追蹤設備維護排程

### 校正管理詳細操作

#### 設定校正提醒
**建議設定**:
- 校正週期：1 年
- Next Due Date = Calibration Date + 365 天
- 系統會在 30 天前開始提醒

#### 查看逾期校正

2. 篩選選擇 **"Overdue"**

## 常見問題

### Q1: 忘記 2FA 怎麼辦？
**A**: 請聯絡 Admin 使用者，由 Admin 執行 "Reset 2FA"。

### Q2: 無法從手機訪問系統？
**A**:
1. 確認手機與電腦在同一 WiFi
2. 使用 `manage.bat → [N]` Network Mode
3. 訪問顯示的 IP 地址
4. 檢查防火牆設定（port 5173, 8000）

### Q3: QR code 掃描後無法開啟？
**A**:
1. 檢查 `.env` 中的 `QR_CODE_DOMAIN` 是否正確
2. 執行 `python update_qr_codes.py` 更新
3. 重新列印 QR code 標籤

### Q4: 上傳檔案失敗？
**A**:
1. 檢查檔案大小（最大 10MB）
2. 檢查檔案格式（PDF, JPG, PNG 等）
3. 確認已登入
4. 重新整理頁面後再試

### Q5: Calibrations 頁面顯示空白？
**A**:
- 正常現象，表示尚無校正記錄
- 建立第一筆 Calibration 即可看到資料

## 技術規格

### 系統架構
```
Frontend (Vue 3 + Vite)
    ↓ HTTP/REST API
Backend (FastAPI + Python)
    ↓ SQLAlchemy ORM
Database (SQLite + WAL mode)
```

### API Endpoints（總計 57 個）
- 認證: 6 endpoints
- 使用者: 7 endpoints
- 設備: 11 endpoints
- 位置: 6 endpoints
- 客戶: 6 endpoints
- 租賃: 10 endpoints
- 校正: 6 endpoints
- 檔案上傳: 9 endpoints
- Dashboard: 3 endpoints

### 資料表（8 個）
1. users（使用者）
2. equipments（設備）
3. locations（位置）
4. equipment_logs（設備日誌）
5. calibrations（校正記錄）
6. log_attachments（日誌附件）
7. trusted_devices（信任裝置）
8. customers, rentals（客戶、租賃）


## 管理工具

### manage.bat 使用

**主選單**:
```
[1] Start All - Localhost Mode
[2] Stop All
[3] Restart All

[4] Start Backend Only
[5] Start Frontend Only
[6] Restart Backend Only
[7] Restart Frontend Only

[8] Stop Backend Only
[9] Stop Frontend Only

[N] Start All - Network Mode (Choose IP)
[S] Check Status
[H] First Time Setup

[0] Exit
```

**Network Mode**:
1. 選擇 `[N]`
2. 選擇 WiFi IP（例如：192.168.1.100）
3. 系統會顯示訪問 URL
4. 手機連同 WiFi 後訪問該 URL

**重要**:
- Restart 操作會記住之前選擇的模式（Localhost/Network）
- Exit 會自動停止所有服務

## 已知限制與注意事項

### 限制
1. **檔案大小**: 最大 10MB
2. **SQLite 限制**: 不支援高並發寫入
3. **圖片格式**: 僅支援常見格式（JPG, PNG 等）
4. **PDF 預覽**: 需在瀏覽器中開啟，無內嵌預覽

### 注意事項
1. **QR Code**: IP 變動後需重新生成並列印
2. **備份**: 定期備份資料庫檔案
3. **防火牆**: Network Mode 需開放 port 5173, 8000
4. **2FA**: 備用碼請妥善保管
